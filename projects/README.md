# projects

One folder for each project. Each folder is a small site of its own: an `index.html`, with its stylesheet and images beside it.

Your homepage links to a project by its folder: `href="projects/recipe/"`.

## To move a Pen in

1. In CodePen, open the Pen. Click the search bar at the top, type `export`, and choose **Export Pen as .zip**.
2. Unzip the download. Open the folder, then the folder named `src`.
3. In your Codespace, make a folder here for the project, such as `projects/recipe/`.
4. Drag everything from `src` into that folder.
5. Commit and sync. Then open the project at your live address: `/projects/recipe/`.

The files sit beside each other the way they did in the Pen, so links between them need no changes. An image that loads from a `codepen` address is the exception: download it, put it in the folder, and change its `src`.
